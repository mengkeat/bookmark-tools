Stanford's CME 295 "Transformers & Large Language Models" offers comprehensive technical curriculum on modern NLP and LLM systems. The course spans September to December 2025 with nine lectures, covering transformer architecture, tokenization, embeddings, and attention mechanisms.

Core content includes architectural variants (multi-head attention, grouped-query attention, rotary positional embeddings), BERT derivatives, mixture-of-experts architectures, context length management, and prompting techniques like chain-of-thought.

Training and tuning covers pretraining, quantization, supervised fine-tuning with LoRA, and alignment via RLHF, reward modeling, and DPO. Advanced topics include reasoning via RL (GRPO), RAG, function calling, agent frameworks like ReAct, and evaluation methodologies using LLMs as judges.
