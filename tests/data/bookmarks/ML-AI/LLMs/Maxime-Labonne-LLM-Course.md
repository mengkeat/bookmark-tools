Maxime Labonne's LLM course is a comprehensive, free resource structured into three parts: LLM Fundamentals (optional), LLM Scientist, and LLM Engineer. The Scientist track focuses on building models using fine-tuning, alignment, and evaluation. The Engineer path emphasizes creating and deploying real-world applications.

Core foundations include mathematics (linear algebra, calculus, probability) and Python programming. The Scientist section covers Transformer architecture, pre-training, supervised fine-tuning (SFT) using LoRA/QLoRA, and preference alignment via DPO, GRPO, and PPO.

The Engineer section covers RAG, agentic workflows with LangChain and LangGraph, deployment with vLLM and TGI, and optimization techniques like quantization and speculative decoding. "When a measure becomes a target, it ceases to be a good measure."
