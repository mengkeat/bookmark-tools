Self-supervised learning (SSL) has emerged as a transformative approach in machine learning, enabling models to learn rich representations from vast amounts of unlabeled data. Unlike supervised learning, which relies on costly and often limited labeled datasets, SSL leverages pretext tasks derived from the input data itself to generate supervisory signals. This paradigm has driven significant advances across domains, particularly in natural language processing with models like BERT and in computer vision with systems trained on billions of images.

The field of SSL encompasses several conceptual families: Deep Metric Learning (SimCLR with contrastive loss), Self-Distillation (BYOL, SimSiam with teacher-student frameworks), Canonical Correlation Analysis (VICReg, Barlow Twins), and Masked Image Modeling (MAE, SimMIM, iBOT). Practical success depends on data augmentation, projector networks, and careful hyperparameter configuration. SSL extends beyond image classification to diverse modalities including audio, video, text, and multi-modal applications like CLIP.
