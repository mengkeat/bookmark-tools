Automatic differentiation (autodiff) computes derivatives of functions specified as computer programs efficiently and accurately. Unlike numerical differentiation (finite differences) which can be imprecise, or symbolic differentiation which can be computationally expensive, autodiff computes exact derivatives using the chain rule.

Two main modes exist: forward mode (computes directional derivatives efficiently for functions with few inputs) and reverse mode (computes gradients efficiently for functions with few outputs). Reverse-mode autodiff is the basis for backpropagation in neural networks, enabling efficient computation of gradients for millions of parameters.
