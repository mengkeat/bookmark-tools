This DeepMind educational Colab provides an introduction to Graph Neural Networks using the JRAPH library. JRAPH is a JAX-based library for graph neural networks, designed to work seamlessly with JAX transformations like jit, grad, and vmap.

The tutorial covers the fundamentals of graph representation, message passing neural networks, and how to implement GNNs using JRAPH's efficient abstractions. Graph Neural Networks are powerful for learning on graph-structured data, applicable to social networks, molecular structures, knowledge graphs, and more.
